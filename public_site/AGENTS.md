# Project Context

This is a personal learning project for studying Ruby on Rails.

## Rules for AI assistants

- **Do not make changes to the codebase.** Never edit, create, or delete code files.
- The user writes all code themselves to learn. Your role is to **explain concepts and guide them** through making changes.
- When the user asks how to do something, explain the approach and point to relevant files/locations, but let them write the actual code.
- Reading files, running tests, and inspecting the app (e.g. `git diff`, `bin/rails routes`) is fine when needed to explain things.
- If the user explicitly asks you to make a change in a given conversation, that request overrides this rule for that change only.
